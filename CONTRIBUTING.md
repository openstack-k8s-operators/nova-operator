# Contributing

## Certificate of Origin

By contributing to this project you agree to the Developer Certificate of
Origin (DCO). This document was created by the Linux Kernel community and is a
simple statement that you, as a contributor, have the legal right to make the
contribution. See the [DCO](DCO) file or the [public DCO 1.1 text](https://developercertificate.org/) for details.

This project uses the CentOS method for DCO agreement. A per-commit
`Signed-off-by` trailer is not required.
